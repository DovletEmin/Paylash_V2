Автоматический бэкап Paylash (Postgres + MinIO)
================================================

Зачем это нужно
----------------
Все файлы студии и вся база данных (пользователи, чаты, права доступа)
хранятся только в двух местах: Postgres (внутри Docker volume postgres_data)
и MinIO (внутри Docker volume minio_data). Если диск умрёт, кто-то случайно
удалит volume, или произойдёт что-то ещё — без резервной копии всё это
пропадёт безвозвратно.

Скрипт backup.ps1 в этой папке каждый день:
  1. Делает pg_dump базы Postgres (обычный текстовый .sql — восстанавливается
     одной командой psql, без специальных инструментов).
  2. Копирует (mc mirror) все бакеты MinIO — то есть все загруженные файлы,
     аватарки, вложения чата — на диск.
  3. Складывает всё в papka backups\ГГГГ-ММ-ДД\ рядом с проектом.
  4. Удаляет бэкапы старше 14 дней, чтобы диск не заполнялся бесконечно.

Что нужно сделать (один раз на каждом ПК)
------------------------------------------
1. Убедитесь, что папка проекта скопирована на этот ПК целиком (включая
   docker-compose.yml, .env и папку scripts) — backup.ps1 сам находит
   всё остальное по своему расположению, его не нужно редактировать.

2. Откройте Планировщик заданий Windows:
       Win + R -> введите taskschd.msc -> Enter

3. Справа нажмите "Create Task..." (НЕ "Create Basic Task").

4. Вкладка General:
   - Name: Paylash backup
   - Поставьте галку "Run whether user is logged on or not"
     (в отличие от автозапуска, бэкап не обязан ждать входа в систему —
     Docker Desktop к моменту ночного бэкапа уже должен быть запущен)
   - Поставьте галку "Run with highest privileges"

5. Вкладка Triggers -> New...:
   - Begin the task: On a schedule
   - Daily, время — например 03:00 (ночью, когда никто не работает)
   - OK

6. Вкладка Actions -> New...:
   - Action: Start a program
   - Program/script:
       powershell.exe
   - Add arguments (optional):
       -ExecutionPolicy Bypass -File "E:\IT-projects\Paylash_V2\scripts\backup.ps1"
     (замените путь на реальный путь к проекту на этом ПК)
   - OK

7. Вкладка Conditions:
   - Снимите галку "Start the task only if the computer is on AC power"

8. Нажмите OK, чтобы сохранить задачу (спросит пароль пользователя — это
   нужно из-за галки "Run whether user is logged on or not").

Как проверить, что всё работает (без ожидания 03:00)
------------------------------------------------------
1. В Планировщике заданий найдите "Paylash backup" в списке слева.
2. Правой кнопкой -> Run.
3. Через несколько секунд откройте scripts\backup.log — там будет видно,
   успешно ли прошли pg_dump и mc mirror.
4. Проверьте, что появилась папка backups\<сегодняшняя дата>\ с файлом
   postgres.sql и подпапкой minio\.

Как восстановиться из бэкапа
-----------------------------
ВНИМАНИЕ: это ПОЛНОСТЬЮ перезаписывает текущую базу данных и все файлы в
MinIO содержимым бэкапа. Использовать только при реальной аварии.

1. Откройте PowerShell в папке scripts:
       cd E:\IT-projects\Paylash_V2\scripts

2. Запустите (укажите нужную дату — имя папки в backups\):
       .\restore.ps1 -Date 2026-07-28

3. Скрипт покажет, что именно будет перезаписано, и попросит явно
   подтвердить, набрав "YES" — без этого ничего не изменится.

4. После восстановления перезапустите приложение:
       docker compose restart app

Хранение бэкапов не на этом же диске
--------------------------------------
Скрипт хранит бэкапы локально, на этом же компьютере — это защищает от
порчи данных (баг, случайное удаление, испорченный volume), но НЕ защищает
от выхода из строя всего диска/ПК целиком. Для более надёжной защиты
периодически копируйте папку backups\ на внешний диск или на другой ПК
в сети вручную, либо настройте синхронизацию этой папки (например, через
обычное сетевое резервное копирование, которое уже может быть в ходу
в студии).
