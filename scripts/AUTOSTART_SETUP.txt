Автозапуск Paylash при включении ПК
====================================

Зачем это нужно
----------------
После перезагрузки ПК Docker Desktop сам поднимает контейнеры (у них стоит
restart: unless-stopped в docker-compose.yml), но делает это "как попало" —
не дожидаясь, пока Postgres и MinIO реально станут готовы. Из-за этого
приложение (paylash-app) стартует раньше базы данных, падает, и сайт не
работает, пока не сделать вручную "docker compose restart".

Скрипт autostart.bat в этой папке решает это: он ждёт, пока Docker
полностью запустится, и только потом выполняет "docker compose up -d" —
эта команда честно ждёт healthcheck-и (Postgres/MinIO -> app -> Caddy) в
правильном порядке.

Что нужно сделать (один раз на каждом ПК)
------------------------------------------
1. Убедитесь, что вся папка проекта (со всеми файлами, включая
   docker-compose.yml и папку scripts) скопирована на этот ПК, например в:
       E:\IT-projects\Paylash_V2

   Файл autostart.bat сам находит путь к проекту (по своему расположению),
   поэтому его не нужно редактировать — просто держите его внутри
   папки "scripts" рядом с docker-compose.yml.

2. Откройте Планировщик заданий Windows:
       Win + R -> введите taskschd.msc -> Enter

3. Справа нажмите "Create Task..." (НЕ "Create Basic Task" — нужны
   дополнительные настройки).

4. Вкладка General:
   - Name: Paylash autostart
   - Поставьте галку "Run only when user is logged on"
     (Docker Desktop работает в пользовательской сессии, поэтому задача
     должна запускаться от имени вошедшего пользователя, а не системы)

5. Вкладка Triggers -> New...:
   - Begin the task: At log on
   - Specific user: текущий пользователь (по умолчанию)
   - OK

6. Вкладка Actions -> New...:
   - Action: Start a program
   - Program/script:
       E:\IT-projects\Paylash_V2\scripts\autostart.bat
   - Start in (optional):
       E:\IT-projects\Paylash_V2\scripts
   - OK

7. Вкладка Conditions:
   - Снимите галку "Start the task only if the computer is on AC power"
     (актуально для ноутбуков; для стационарного ПК можно не трогать)

8. Нажмите OK, чтобы сохранить задачу.

Как проверить, что всё работает (без перезагрузки ПК)
-------------------------------------------------------
1. В Планировщике заданий найдите "Paylash autostart" в списке слева.
2. Правой кнопкой -> Run.
3. Откройте scripts\autostart.log — там будет видно:
   - дождался ли скрипт готовности Docker
   - с каким кодом завершился "docker compose up -d"

Если через несколько минут после ПКМ -> Run сайт открывается сам —
всё настроено правильно, и после следующей перезагрузки ПК ничего вручную
делать не понадобится.

Также убедитесь, что сам Docker Desktop запускается автоматически:
Docker Desktop -> Settings -> General ->
"Start Docker Desktop when you log in" (галка должна быть включена).
